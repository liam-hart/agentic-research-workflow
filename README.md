# Agentic research workflow

A starter kit for doing research with AI coding agents. Clone it, and you have a project that an agent can orient in: an instruction file it reads first, rules, skills, a place for current state, and a trail of handoffs.

It comes from a working PhD research setup in cognitive neuroscience. Other people are not named, and projects and places appear as placeholders such as "Project A" and "the lab".

## Start here

1. Clone the repository, or use it as a template for a new one.
2. Open the folder with your agent (Claude Code, Codex, Cursor, or another client that reads `AGENTS.md`).
3. Edit `AGENTS.md`. It is the one file every agent reads first, so put your own rules, prohibitions, and "ask me before" list there.
4. Read `docs/principles.md` (five minutes), then `docs/architecture.md`.
5. Keep the skills you want under `.agents/skills/` and delete the rest. Many refer to scripts and folders from the original setup; treat those as worked examples and adapt them.

## What is in the box

| Path | What it is |
|---|---|
| `AGENTS.md` | Starter instructions for agents: authority, what needs asking, how a session closes |
| `CLAUDE.md` | One line that points Claude Code at `AGENTS.md` |
| `.agents/rules/` | Short rules that apply to particular paths or kinds of task |
| `.agents/skills/` | Skills: one folder each, with a `SKILL.md` an agent loads before that kind of task |
| `operations/STATE.md` | Current gates, blockers, and next pickups, rewritten in place |
| `operations/handoffs/` | One note per session: what changed, how it was checked, what is open |
| `operations/templates/` | The template new skills are written from |
| `docs/` | The method: principles, architecture, playbooks, decisions |
| `docs/reference/` | The skill list, generated by `tools/list_skills.py` from the skills that ship here. Do not edit it by hand |
| `tools/privacy_check.py` | A check for user paths, email addresses, and Obsidian wikilinks; it runs on every pull request |
| `tools/list_skills.py` | Rebuilds the skill list; `--check` fails when it is out of date |
| `.github/workflows/privacy.yml` | Runs the tool tests, the skill-list check, and the privacy check |

## Skills follow an open format

Skills here use the Agent Skills format: a folder with a `SKILL.md` that has a `name`, a `description` saying when to use it, and instructions. The specification and a validator live at <https://github.com/agentskills/agentskills>. Any client that supports the format can load these skills.
