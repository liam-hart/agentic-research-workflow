# Framework evaluation

Use this reference when comparing mature theoretical accounts.

- Define each account's explanandum and level of analysis.
- Separate redescriptions of the phenomenon from proposed mechanisms.
- State the assumptions connecting mechanism, observable, and prediction.
- Identify predictions shared by the accounts and predictions that discriminate them.
- Check scope conditions, boundary conditions, moderators, and counterevidence.
- Distinguish direct evidence, converging indirect evidence, and post-hoc compatibility.
- Name the observation that would require revising each account.
- Route the critical test to `experiment-design`; do not choose protocol or model details here.
