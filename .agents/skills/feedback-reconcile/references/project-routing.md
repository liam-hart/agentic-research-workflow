# Conditional project routing

Use this only after reading the live project authority. The table below is an invented example of how projects in one workspace might differ; replace it with your own routing and keep it current.

| Project pattern | Candidate task authority | Candidate decision authority |
|---|---|---|
| Manuscript project (example: "Paper 1") | `projects/paper-1/Manuscript Status.md` | the same file's decision sections |
| Study project (example: "Study 2") | `projects/study-2/Tasks.md` | `projects/study-2/Decision Log.md` |
| Methods project (example: "Toolbox") | `projects/toolbox/Tasks.md` | `projects/toolbox/Decision Log.md` |
| Single-file projects or areas | current action-items authority | the same file when it contains decisions |

Before routing, list the target file's actual headings and confirm the intended destination exists. If the path or heading differs, show the current options and stop for confirmation. Never create a heading merely to make a route work.
