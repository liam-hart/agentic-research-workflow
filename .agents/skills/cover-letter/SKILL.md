# Cover Letter

Produce a submission cover letter, an R&R cover letter, or a point-by-point response to reviewers that follows the curated genre sources. Grounds every draft in curated APA Style / UNC Writing Center / CMU / PLOS sources — never draft cover-letter or response-to-reviewers structure from model priors alone when these resources exist.

## 1. Detect mode

Ask (or infer from context) which package is needed:

- **Initial submission** → one artifact: short cover letter.
- **R&R / resubmission** → two artifacts unless the researcher asks for only one:
  1. short **cover letter** (summary + thanks + pointer to the response doc)
  2. detailed **response to reviewers** (point-by-point)

## 3. Checklists

Read the checklist that matches the mode from § 1 while drafting:

- [references/checklist-initial.md](references/checklist-initial.md) for an initial submission cover letter.
- [references/checklist-rr.md](references/checklist-rr.md) for an R&R cover letter and the response-to-reviewers document.

## 4. Drafting rules

- Never paste the abstract into the cover letter — briefly state contribution + journal fit instead.
- Keep the R&R cover letter short (summary + thanks + pointer); put all point-by-point detail in the separate response document.
- In the response document: quote or restate each comment, typographically distinguish comment vs. author response vs. quoted manuscript text (e.g., "Author response:" in a different color/font), locate every change (page/paragraph/line), stay polite and non-defensive, accept blame for clarity issues, justify — don't just refuse — any declined change.
- Maintain an internal comment → disposition/status → canonical change location tracker. `feedback-reconcile` owns routing comments into project task authority; the outward reviewer response is derived from that settled state, not a replacement for it.
- Keep reviewer-facing sections self-contained without leaking internal task language or another reviewer's private/contextual material. After any substantive manuscript change, recheck quoted replacement text, page/line locations, the response tracker, and marked versus clean manuscript artifacts as one coupled package.
- Preserve the corresponding-author / authorship-agreement / ethics / permissions / conflict-of-interest elements even when drafting a short letter; these are frequently required regardless of length.

## 5. Masked-review journal overlay

When drafting for a masked-review journal: remind the researcher that masked review requires keeping author-identifying info (names, affiliations, acknowledgments, identifiable IRB/OSF links) out of the blinded manuscript, using anonymized OSF links for review, and that data-transparency statements belong in the cover letter / manuscript per current journal instructions — verify against the live journal submission page rather than assuming.

## 6. Output

- Produce the polished letter(s) ready to paste.
- Append a short **"Source basis"** note listing exactly which curated files (from §2) were used for this draft.
- Save only when requested. Use the manuscript project's documented submission-artifact authority; if no destination is documented, ask rather than treating a journal cover letter or response document as ordinary outgoing email. Your message-drafts folder is only for actual email/message drafts.

## 7. Verification

- The "Source basis" note names only § 2 files that were read for this draft.
- In a response document, every reviewer comment has a response, and each stated change gives a page, paragraph, or line location that matches the current manuscript.
- Journal-specific requirements were checked against the live submission page, not recalled.
