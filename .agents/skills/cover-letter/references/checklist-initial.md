# Initial Submission Cover Letter Checklist

Derived from `apa-cover-letters.md` (APA Style, Section 12.11) and `unc-journal-article-publication-letters.md` (UNC Writing Center).

## Required elements (APA)

- Addressed to the journal editor (check journal website for current name)
- Manuscript title
- Manuscript authors
- Assurance all authors agree with content and byline order
- Assurance corresponding author will keep coauthors informed of decisions/reviews/revisions
- Disclosure of any closely related manuscripts submitted elsewhere (simultaneous consideration / piecemeal-publication transparency)
- Conflicts-of-interest statement
- Masked-review request, if desired and offered by the journal
- Ethics statement (human/animal subjects treatment per established standards, IRB approval)
- Permissions for reproduced copyrighted material — granted or pending
- Corresponding author's phone, email, mailing address

## Contribution / fit content (UNC)

Include each of these:

- Brief summary of major findings/argument — do NOT paste the abstract
- Explicit connection to the journal's aims and scope
- Brief methodology note (design type, framework/theoretical lens) if the journal expects it
- Prior presentation disclosure, if applicable (e.g., conference presentation of some data)
- Suggested/excluded reviewers, only if the journal invites this — state rationale for exclusions

## Form

Confirm each before sending:

- Addressed to editor by name; journal's address, not personal
- Standard readable font, non-indented single-spaced paragraphs
- One page unless senior-scholar exception applies
- Formal close with typed name, signature, full contact block

## Pitfalls to avoid (UNC)

- Jargon/acronym overload
- Over-embellishing findings
- Name dropping
- Longer than necessary
- Informal tone/humor
- Copying manuscript text verbatim into the letter
