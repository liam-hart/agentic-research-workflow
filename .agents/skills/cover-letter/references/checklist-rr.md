# R&R Cover Letter + Response-to-Reviewers Checklist

Derived from `apa-cover-letters.md`, `apa-response-to-reviewers-guide.md`, `sample-response-reviewers.md`, `writing-revise-resubmit-letter.md` (CMU), and `file.md` (Noble 2017 ten simple rules).

## R&R cover letter (short)

Every item below must be present in the letter before it is done:

- Manuscript number, title, authors
- Thanks to editor and reviewers for the opportunity to revise / for their feedback
- High-level summary of changes made (and, if any, changes NOT made — with a one-line rationale category, not full detail)
- Explicit pointer to the separate response-to-reviewers document, including its formatting convention (e.g., numbered comments, distinguishing color/font for "Author response")
- Stay short — do not re-litigate individual reviewer points here; that's the response document's job
- Same contact block / corresponding-author info as the initial letter

## Response to reviewers (detailed document)

CMU's 5 rhetorical moves (apply in this order):

1. **Express gratitude** — open with thanks for reviewers' time and detailed comments
2. **Signal attention to comments** — state explicitly, early, that every comment was considered
3. **Claim positive results** — acknowledge the manuscript improved as a result
4. **Preview content** — give the editor a roadmap for how the response is organized
5. **Respond to specific comments** — the bulk of the document; point-by-point

Per-comment structure (APA + Noble):

- Restate or quote the reviewer's comment verbatim
- Typographically distinguish comment vs. author response (e.g., "Author response:" in a different color)
- Explain the specific change made, and locate it (page/paragraph/line) in the revised manuscript
- For declined suggestions: politely and non-defensively justify why, citing scope/data constraints or literature support — never simply refuse
- For correctness-type comments (typos, factual slips): thank the reviewer plainly, don't over-explain
- For "beyond scope" requests: acknowledge the value of the suggestion before declining
- Keep tone polite throughout — reviewers critique the work, not the author (per CMU + Noble)
- Cross-check that every reviewer comment received a response — none silently skipped
