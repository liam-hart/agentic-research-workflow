# Rules

A rule is a short file that applies to a path or a kind of task. An agent that does not load rules automatically reads the matching one before it touches a matching path.

## Always-on rules

| Applies to | Canonical rule | Purpose |
|---|---|---|
| Any multi-step task | `.agents/rules/delegation.md` | Decide what to hand to a subagent and what to keep |
| A choice about structure, tools, or taste | `.agents/rules/collaborative-decisions.md` | Bring the decision back to the owner |
| Closing any session | `.agents/rules/handoff-signoff.md` | End every handoff with a verified sign-off |
